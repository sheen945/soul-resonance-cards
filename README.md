# 心灵共振 · Soul Resonance Cards

> 36 个问题，让两个灵魂慢慢靠近。
> 源自阿伦（Arthur Aron）亲密关系实验 36 问，全套中文化改写。

🎴 **在线试玩（国内推荐）**：见下方 Cloudflare Pages 演示地址
⭐ **GitHub Pages**：https://sheen945.github.io/soul-resonance-cards/

## 这是什么

一个聚会破冰卡牌网页游戏。两个互不相识的人（或情侣、兄弟、闺蜜）通过由浅入深的 36 个问题，逐步自我暴露、拉近距离。

- 📱 手机浏览器打开即玩，可「添加到主屏幕」
- 🀄 全中文题库，按中国语境重写，分寸按模式把控
- 🎨 每张题卡配专属新中式暗金插画（AI 生成，共 169 张）
- 🌙 暗夜金视觉，聚会暗光环境友好

## 四种模式

| 模式 | 场景 |
| --- | --- |
| 通用破冰版 | 初次见面、聚会破冰，分寸温和 |
| 情侣版 | 恋人之间，可以更亲密 |
| 哥们版 | 好兄弟局，事业义气糗事 |
| 集美版 | 闺蜜局，情感审美心事 |

每种模式 36 题，三层递进：破冰暖场 → 深入内心 → 灵魂拷问。

## 玩法

1. 选模式 → 选人数（2-8 人）→ 轮流抽卡
2. 同一道题所有人答完才进入下一题
3. 每人 3 次豁免机会；用完后可选择「喝一口」（可用饮料代替）或表演才艺/大冒险（抽惩罚卡，共 20 张）
4. 听到打动你的回答，点 ❤️ 标记，结束后生成「今晚的共振」回顾页
5. 🥚 彩蛋：结束后有概率触发隐藏环节「对视 4 分钟」——阿伦实验的精髓

## 技术说明

纯静态站点：`index.html` + `questions.json` + `images/`（WebP）。无任何依赖、无任何数据上传，标记数据当局有效、退出即清空。

音效由 WebAudio 实时合成，零音频文件。
